  Promotion : Trash Bags @ MassRetailer, wk 27, 38% off, display=endcap, feature=no  (1 week)
  Neural network : average lift 246.2%   extra units 111,728

      VIOLATION  minimum margin after discount (limit 10%)

      guideline  overlaps a scheduled promotion (SCH-1), certainty 0.70
      combined certainty of guidelines: 0.80  (0.50 or more = needs review)
  Why (inference chain):
      Review(S2, deep discount (30%+), 0.38)   <- R9: deep discounts can train shoppers to wait for sales
          because Discount(S2, 0.38)
      Review(S2, overlaps a scheduled promotion, SCH-1)   <- R7: overlaps a scheduled promotion in the same shelf group at the same retailer
          because Promotion(S2)
          because Scheduled(SCH-1)
          because Retailer(S2, MassRetailer)
          because Retailer(SCH-1, MassRetailer)
          because Category(S2, Trash Bags)
          because Category(SCH-1, Trash Bags)
          because InGroup(Trash Bags, Bags)
          because ActiveWeek(S2, 27)
          because ActiveWeek(SCH-1, 27)
      Violation(S2, minimum margin after discount, 0.1)   <- R6: gross margin after the discount below the company minimum
          because PromoMargin(S2, 0.0)
          because MinPromoMargin(0.1)
      Violation(S2, price floor, 5.23)   <- R4: shelf price below the price floor (MAP)
          because ShelfPrice(S2, 4.84)
          because Category(S2, Trash Bags)
          because MinShelfPrice(Trash Bags, 5.23)
      Violation(S2, retailer discount cap, 0.35)   <- R1: retailer discount cap
          because Retailer(S2, MassRetailer)
          because Discount(S2, 0.38)
